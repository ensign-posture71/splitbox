# Домашний policy-routing шлюз: MikroTik + sing-box VM

Три пути трафика для всех устройств дома, без настройки на самих устройствах:
**работа** (WireGuard) · **напрямую** (по умолчанию, RU) · **за рубеж** (VLESS+Reality через VM).

Архитектура — [`docs/architecture.md`](docs/architecture.md). Решения и находки — [`docs/decisions.md`](docs/decisions.md).

## Структура

| Каталог | Содержимое |
|---|---|
| `baseline/` | Экспорт исходного конфига роутера (до изменений). Сырые `.rsc` в Git не идут — только очищенные. |
| `router/` | RouterOS-скрипты: таблицы, mangle-классификатор, WireGuard, address-lists. |
| `vm/` | Конфиг sing-box + systemd unit для VM на Proxmox. |
| `sync/` | Скрипт «abroad-список → address-list на роутере» (Вариант A). |
| `secrets/` | Ключи WG, параметры Reality. **Не в Git.** |
| `docs/` | Архитектура, журнал решений. |

## Статус шагов (§6 архитектуры)

- [ ] **Шаг 0** — инвентаризация + Git-скелет · *скелет готов, baseline блокирован доступом к роутеру*
- [ ] **Шаг 1** — плоскость роутера (таблицы, wg-work, wg-clients, классификатор)
- [ ] **Шаг 2** — VPS Reality (реюз существующего, D3)
- [ ] **Шаг 3** — плоскость VM (sing-box + sync-скрипт)
- [ ] **Шаг 4** — отказоустойчивость и чек-лист диагностики

## Зафиксированный выбор

- §5 → **Вариант A**: тонкий IP-список на роутере, мозг на VM, fail-open в direct.
- Линк роутер↔VM → **общий LAN-сегмент** `192.168.88.0/24`.
- VPS → **реюз** существующего VLESS+Reality.
