Шаг 1 · Проверьте на одном устройстве

Ничего не меняя в роутере: вы вписываете адреса вручную только на одном компьютере или телефоне. Не понравится — вернёте «автоматически», и всё будет как прежде.

Windows
Параметры → Сеть и Интернет → ваше подключение → «Изменить» у пункта «Назначение IP» → вручную → IPv4 включить. Шлюз и «Предпочитаемый DNS» — {{ box_ip }}. IP-адрес оставьте свой, маску 255.255.255.0.
macOS
Системные настройки → Сеть → Wi-Fi → «Подробности» → TCP/IP: «Вручную», маршрутизатор — {{ box_ip }}; вкладка DNS: добавить {{ box_ip }} и убрать остальные.
iPhone / iPad
Настройки → Wi-Fi → «i» у сети → «Настройка IP» → «Вручную»: маршрутизатор {{ box_ip }}. Ниже «Настройка DNS» → «Вручную» → {{ box_ip }}.
Android
Настройки → Wi-Fi → удерживать сеть → «Изменить сеть» → Дополнительно → «Пользовательские»: шлюз и DNS 1 — {{ box_ip }}.

Через минуту вернитесь на эту страницу: сверху должно появиться зелёное сообщение, что трафик пошёл. Проверьте заодно на странице статистики — там видно, какое устройство и куда ходило.

Шаг 2 · Переключите всю сеть

Когда убедились, что на одном устройстве всё работает. Дальше выберите то, что ближе вашему роутеру.

Обычный роутер (Keenetic, TP-Link, ASUS, Tenda…)
Меняется одна страница настроек — DHCP.
  1. Откройте настройки роутера (обычно 192.168.1.1 или 192.168.0.1).
  2. Найдите раздел DHCP-сервер (бывает внутри «Домашняя сеть» или «LAN»).
  3. Поле Основной шлюз (Default Gateway) — впишите {{ box_ip }}.
  4. Поле DNS-сервер — тоже {{ box_ip }}.
  5. Сохраните. Устройства подхватят настройки в течение часа — или сразу, если выключить и включить Wi-Fi.
Если поля «Основной шлюз» нет — роутер этого не умеет. Тогда остаётся вариант «только блокировка рекламы» ниже либо ручная настройка на каждом устройстве.
MikroTik — без риска для всей сети
Правильный способ: отдельная таблица маршрутизации с автоматическим возвратом, если коробка пропадёт.
# 1. ОБЯЗАТЕЛЬНО: собственный трафик коробки не маркировать.
# Без этого правила пакет, отправленный коробкой наружу, вернётся
# на неё же — маршрутизация закольцуется и сеть встанет целиком.
/ip firewall mangle add chain=prerouting action=accept     src-address={{ box_ip }}     place-before=[find where new-routing-mark~"." and chain="prerouting"]     comment="splitbox: без маркировки (иначе петля)"

# 2. Если на роутере включён принудительный DNS — разрешить коробке
#    ходить к внешним резолверам напрямую (иначе она не разрешит
#    даже адрес вашего сервера).
/ip firewall address-list add list=dns-allowed address={{ box_ip }}     comment="splitbox: прямой DNS разрешён"

# 3. Маршрут в коробку. check-gateway=ping + запасной маршрут:
#    если коробка пропадёт, сеть сама вернётся к прямому выходу.
/ip route add dst-address=0.0.0.0/0 gateway={{ box_ip }}     routing-table=splitbox check-gateway=ping distance=1
/ip route add dst-address=0.0.0.0/0 gateway=WAN-ШЛЮЗ     routing-table=splitbox distance=10

# 4. Заворачиваем трафик локальной сети
/ip firewall mangle add chain=prerouting in-interface-list=LAN     action=mark-routing new-routing-mark=splitbox passthrough=no     comment="splitbox"

# 5. fasttrack обходит маршрутизацию — исключаем помеченное
/ip firewall filter set [find action=fasttrack-connection]     routing-mark=no-mark
Замените WAN-ШЛЮЗ на адрес шлюза провайдера (/ip route print, строка с 0.0.0.0/0). Порядок правил важен: пункты 1 и 2 должны выполняться до пункта 4. DNS переключается отдельно: в DHCP-сети укажите {{ box_ip }}.
Проверьте сразу после включения — откройте любой сайт с другого устройства. Если связи нет, откат: /ip route remove [find gateway={{ box_ip }}].
Только блокировка рекламы
Если трогать маршрутизацию не хочется: укажите коробку только как DNS. Реклама режется, но туннель работать не будет — заблокированные сайты не откроются.
В роутере: DHCP → DNS-сервер → {{ box_ip }}.

Доступ извне (WireGuard)
Чтобы телефон подключался из поездки, роутер должен пропускать соединение внутрь.
  1. В роутере найдите Проброс портов (Port Forwarding, Virtual Server, NAT).
  2. Внешний порт {{ cfg.wireguard.listen_port }}, протокол UDP.
  3. Внутренний адрес {{ box_ip }}, порт тот же.
Нужен «белый» IP от провайдера. Если адрес серый (за общим NAT), подключение снаружи не заработает — спросите у провайдера белый адрес, обычно это платная опция.

Если что-то пошло не так

Коробка сделана так, чтобы не оставить вас без интернета: если туннель сломается, она сама перестаёт перехватывать трафик, и сеть продолжает работать напрямую. Но если что-то не так с самой коробкой:
  1. Верните прежние настройки роутера — в DHCP укажите обратно адрес роутера в полях «Шлюз» и «DNS». Для MikroTik: /ip firewall mangle disable [find comment=splitbox].
  2. На устройстве, где меняли вручную, верните «Автоматически».
  3. Перезагрузите устройство или переподключите Wi-Fi.
Панель коробки останется доступна по адресу https://{{ box_ip }}:8443 в любом случае — она не зависит от того, идёт через неё трафик или нет.
